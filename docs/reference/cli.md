# Command line

```text
pydebuprep [COMMAND] [OPTIONS]
pydebuprep --version | --help
```

Without a command, `report` runs: `pydebuprep --format html` is
`pydebuprep report --format html`. Commands are only recognised as the first word.
`pydebuprep COMMAND --help` prints a command's options.
